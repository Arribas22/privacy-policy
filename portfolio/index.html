Enfusion Engine · EnforceScript

Game Systems Engineering — Full Stack

EnforceScript es un lenguaje derivado de C orientado a objetos que potencia el motor Enfusion (Arma Reforger). He diseñado e implementado el framework RP íntegramente: lado cliente (todas las interfaces de usuario, HUDs, menús y lógica del jugador) y lado servidor (autoridad de juego, persistencia, seguridad y backend de datos).

🖥️

Frontend — Lado Cliente

Desarrollo completo de todas las interfaces de usuario en Enfusion UI: menús de personaje, HUD, teléfono, tiendas, garage, GPS, chat y notificaciones en pantalla. Toda la lógica del lado cliente y los RPCs de comunicación con el servidor.

⚙️

Backend — Lado Servidor

Autoridad completa del servidor: economía, inventarios, vehículos, grupos y misiones. Integración con progressSQL para persistencia total. Sistema de save data serializable por componente (EPF). Lectura/escritura asíncrona entre reinicios.

🔌

Proxy de Conexión Personalizado

Proxy propio para la comunicación entre el servidor de juego y la base de datos externa. Manejo de reintentos, carga asíncrona y callbacks que garantizan integridad de datos.

🗄️

Evolución del Backend de Datos

El sistema empezó con archivos .json locales, escaló a MongoDB para consultas flexibles y finalmente migró a progressSQL para máximo rendimiento y persistencia relacional.

JSON → MongoDB → progressSQL
