Enfusion Engine · EnforceScript

Game Systems Engineering

EnforceScript es un lenguaje derivado de C orientado a objetos que potencia el motor Enfusion (Arma Reforger / DayZ). He desarrollado un framework RP completo que va desde sistemas de gameplay hasta infraestructura de persistencia backend.

⚙️

Backend de Persistencia

Integración con progressSQL para almacenamiento total del progreso de jugadores entre sesiones. Lectura/escritura asíncrona desde el servidor dedicado. Sistema de save data serializable por componente (EPF).

🔌

Proxy de Conexión Personalizado

Proxy propio para la comunicación entre el servidor de juego y la base de datos externa. Manejo de reintentos, carga asíncrona y callbacks para garantizar integridad de datos en reinicios del servidor.
